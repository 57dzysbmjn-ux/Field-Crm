# Field CRM Prototype

A simple mobile-first CRM prototype for customers, estimates, quick notes, and scheduling.

## Deploy with GitHub and Vercel

1. Create a new GitHub repository named `field-crm`.
2. Upload every file in this folder to the repository root.
3. In Vercel, select **Add New > Project**.
4. Import the `field-crm` GitHub repository.
5. Leave Framework Preset as **Other** and click **Deploy**.
6. Open the Vercel URL on an iPhone in Safari.
7. Tap **Share > Add to Home Screen**.

## Current limitation

This prototype stores data in the browser on each device. It does not yet sync between two phones. Use **Settings > Export Backup** to save a copy of the data.
